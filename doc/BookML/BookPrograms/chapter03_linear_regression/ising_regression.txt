=== 1. the design matrix ===
  L = 40 spins, n = 10000 configurations, J = 1.0
  design matrix X with X[i, j*L+k] = s_j s_k : shape (10000, 1600)
  energies: min -20, max 24, mean 0.0388, std 6.3094

  Two exact facts about this design matrix, both structural:
    (a) the L diagonal columns are s_j^2 = 1 identically, so they
        are all equal to the constant column and to each other;
    (b) column (j,k) and column (k,j) are identical, since
        s_j s_k = s_k s_j.

  max |X[:, diagonal] - 1|                    : 0.000e+00
  max |X[:, (j,k)] - X[:, (k,j)]| over all j<k: 0.000e+00

  distinct columns therefore number L(L-1)/2 + 1 = 781,
  so rank(X) <= 781 however many configurations we draw.
  measured rank(X) with n = 10000 rows          : 781
  number of columns p = L^2                   : 1600
  singular values: sigma_0 = 633.8002, sigma_780 = 1.0218e+02, sigma_781 = 4.7516e-13
  ratio sigma_780 / sigma_781 : 2.150e+14
  the spectrum falls off a cliff exactly where the counting says it
  must: X^T X is singular by construction, not by rounding

=== 4. Proposition 3.duplicate, checked on the (j,k)/(k,j) pairs ===
  With two identical columns the 2-norm estimators must give the two
  coefficients the same value, and the 1-norm need not.

   estimator            max |J[j,k] - J[k,j]| over all j<k
   OLS (pseudoinverse)                           9.437e-16
   Ridge, lambda = 0.01                          0.000e+00
   Lasso, lambda = 0.01                          9.990e-01
  OLS and Ridge are symmetric to machine precision, as the
  proposition requires; the Lasso is not, and puts the whole coupling
  on one side of the pair.

  and the objective is genuinely indifferent to the split: taking the
  Lasso solution and symmetrising each (j,k)/(k,j) pair,
    Lasso objective at the solver's answer : 0.3988830154
    Lasso objective at the symmetrised one : 0.3988830154
    max |fit difference| on the test set   : 7.105e-15
  identical to ten decimals and identical in the fit, which is
  Proposition 3.lassofit: the fit is unique, the coefficients are not
