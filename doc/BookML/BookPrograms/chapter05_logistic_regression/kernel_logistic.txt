=== 0. the problem ===
  120 points in the plane, class 1 inside a disc of radius sqrt(3), 5% of the labels flipped;
  52 positives, 68 negatives.  No linear boundary can do better than chance here.

=== 2. the kernel form against an explicit feature map ===
  With the quadratic kernel (x.x' + 1)^2 the feature map is only
  six-dimensional, so the primal problem can be solved directly and
  the two answers compared.

  max |k(x,x') - phi(x).phi(x')|: 4.263e-14
  max |f_kernel(x) - f_primal(x)| on 400 test points: 6.004e-13
  ||theta_primal||^2 = 13.2542532295,   alpha^T K alpha = 13.2542532295
  the two penalties are the same number because both are the squared
  norm of the same function in the same space

  scikit-learn in the same map, C = 1/lambda:
    max |theta_ours - theta_sklearn| : 9.498e-09
    max |f_ours - f_sklearn| on test : 7.232e-08

=== 3. Proposition 5.kalpharesidual: alpha = (y - p) / lambda ===
  Setting the gradient K[(p - y) + lambda alpha] to zero and using
  that K is invertible gives alpha_i = (y_i - p_i) / lambda: the
  dual coefficient of a point is its residual, divided by the
  penalty.  Residuals are never exactly zero, so alpha is dense.

   lambda   max |alpha - (y-p)/lambda|   non-zero alpha of 120   |alpha|_min
     0.10                   1.471e-11                 120   2.065e-02
     1.00                   1.477e-13                 120   6.360e-02
    10.00                   1.422e-15                 120   3.472e-02
  every one of the coefficients is non-zero at every penalty; the
  contrast with the support vectors of Chapter 6 is the whole point
  of Theorem 6.threelosses

  constant.  The best test accuracy is in between, which is
  Eq. (2.biasvariance) once more.
